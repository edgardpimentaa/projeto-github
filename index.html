02 / O movimento

Uma ideia.
Um fluxo.

O GitHub organiza o caminho entre pensar, fazer e compartilhar. Veja como as peças se conectam.

01

Crie

Abra um repositório e centralize os arquivos do seu projeto.

02

Trabalhe

Crie uma branch, faça mudanças e registre commits claros.

03

Colabore

Abra uma pull request, receba feedback e melhore junto.

04

Publique

Faça o merge e deixe seu trabalho pronto para o mundo.
